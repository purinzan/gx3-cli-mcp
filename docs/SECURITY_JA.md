# セキュリティノート

`gx3-cli-mcp` は、GX Works3 プロジェクトをローカルで読み取り解析するためのツールです。利用者が `report-issue --yes` などで明示的に送信しない限り、プロジェクトデータを外部へ送信しません。

## 利用者が知るべきこと

- `.gx3` はローカルの `.gx3_cache\<sha256>\` に展開されます。
- 解析用の SQLite DB、CSV、Markdown、ZIP などがローカルに生成される場合があります。
- `report-issue` は `--yes` が指定された場合だけ、匿名化済みの診断要約を GitHub Issue として送信します。
- MCP サーバーは project-read-only の解析入口を公開します。
- MCP から合成デモ生成、プロジェクト変更系コマンド、外部送信コマンドは実行できません。
- このリリースでは MCP サーバーに license token は不要です。

## 生成される可能性があるファイル

| 種類 | 例 | 用途 |
|---|---|---|
| 展開キャッシュ | `.gx3_cache\<sha256>\` | `.gx3` 内部ファイルをローカル解析するため |
| SQLite DB | index / xref DB | デバイス検索、コメント検索、writer/reader 検索 |
| CSV / Markdown | lint, report outputs | 解析結果の確認、共有、記録 |
| ZIP | `support-bundle` | サポート用の診断情報まとめ |
| 匿名化テーブル | `.gx3_redaction\` | ローカル復元用の実名/別名対応。共有しない |

生成物を共有する前に、社内ルールに従って内容を確認してください。

## MCP の安全方針

- MCP は読み取り解析を中心にした allowlist です。
- GX Works3 プロジェクトを書き換える操作は MCP から公開していません。
- `report-issue` / `send-report` は GitHub Issue 送信を行うため MCP から公開していません。
- `gx3_run_command` は便利な escape hatch ですが、MCP-safe なコマンドだけに制限されています。
- 実プロジェクトを AI クライアントに扱わせる場合は、その AI クライアント側のデータ送信ポリシーも確認してください。

## 運用上の注意

- このツールの出力だけで、実 PLC や生産設備への変更判断をしないでください。
- 解析結果は GX Works3 などの正式なエンジニアリング環境で確認してください。
- 安全回路、インターロック、停止条件、設備改造に関わる判断は、現場の安全確認とレビューを優先してください。
- Issue、スクリーンショット、公開資料には実プロジェクト由来の機密情報を載せないでください。
